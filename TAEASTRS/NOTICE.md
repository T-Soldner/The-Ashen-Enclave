The Ashen Enclave TFAR Setter

This addon packages and lightly adapts ASTRS - A Simple TFAR Radio System for
The Ashen Enclave mod.

Original project:
https://github.com/chatterchats/ASTRS

Original authors:
Chatter and M3ales

License:
MIT. See LICENSE in this folder.

TAE changes:
- Renamed the addon class to TAEASTRS to avoid conflicts with standalone ASTRS.
- Kept the TFAR beta-compatible tfar_core dependency instead of task_force_radio.
- Updated metadata for The Ashen Enclave packaging.
