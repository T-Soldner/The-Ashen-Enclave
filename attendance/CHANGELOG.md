  Discord roles. Pilot qualifications have restricted approval permissions.

- Added a previewed Unit Roster update and a separate color-coded Training Tracker.
- Preserved existing attendance totals, legacy specialization records and radio
  frequencies.
- Added a previewed import of existing yellow/green qualification marks, without
  changing Discord roles. Historical over-budget selections are retained for review.
- Added explicit member matching for renamed/abbreviated legacy records.

These source changes are not deployed yet. Live tests remain pending. Technical
setup and rollout details are in CLANS_AND_TRAINING.md, separate from these notes.
